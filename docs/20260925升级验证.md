# 2026.09.25-upgrade.1 发布验证

本版为旧汉化升级候选，未做本版游戏内回归验收。公开发行范围是升级器源码、说明及资源差分，不包含完整游戏、影片、存档、授权文件或密钥。

## 基线与改动范围

- 基线：`v2026.09.17-delta.1` / `BLJS10050_CN_20260917_r1`，官方 1.02 更新已汉化。
- 旧公开 Core ZIP SHA-256：`9dfdeb58264e51ee5ffed8ff77b9adbb5ce486ed0a166bb90ca6681cc5753013`。
- 22 个本体成员（4 个界面资源、18 个 XMB 文本）逐一核对旧版来源。旧差分未改动的补给 FPK 另外通过旧整合版 `game.arb` 核对，整合版整档 SHA 与公开 Core 清单目标一致。
- 两份更新 SDAT 基线 SHA 与旧公开清单一致。新 SDAT 的制作阶段已通过认证解码/编码往返及其他成员不变检查；发行差分不需要用户提供密钥。
- 每个成员/文件的安装前后 SHA、字节数和差分指令见 `upgrade/upgrade-manifest.json`。仅目标资源匹配的基线可安装；未知及混合版本拒绝写入。
- 资源之外的低特效修改保留。影片、本体执行文件、模拟器配置、存档及奖励规则不在写入范围。

## 安装器验证

在 macOS / Python 3 标准库环境执行；Windows / Linux 启动器未实机执行。

16 项合成资源测试全部通过：

- 正常安装、重复安装无写入、已有缓存同步、精确恢复及范围外标记保留。
- 未知基线、混合版本、错误更新版本、缺少更新、缺失或损坏差分、路径越界拒绝。
- 目标只读、空间不足、准备阶段失败均不写入游戏。
- 写入中断、文件部分扩展中断、恢复过程再次中断，均能根据事务记录恢复。
- 恢复前检查备份哈希，并拒绝覆盖安装后出现的未知资源修改。

旧首次安装器的 8 项回归测试也通过。原存档导入器源码和既有发行未改动。

另在全新临时目录解压**最终发行 ZIP**，以实际的 22 个旧版资源、真实两份 SDAT 和原版索引构造本体/缓存测试容器，依照安装器完成：预检 → 安装 → 重复检查 → 回读全部新资源 SHA → 恢复 → 全容器及两份 SDAT 恢复 SHA 核对。

测试容器的未涉及区域使用稀疏占位数据，并加入未修改区域标记，避免复制整套游戏。它验证的是安装路径、索引、实际差分资源及恢复一致性，**不能用来证明游戏可启动或各场景实际显示正确**。本机实际游戏的候选资源已完成静态回读，运行仍由用户手动验收。
