# 安装与排错指南

## 下载和准备

下载 Releases 中 Core、Movies1、Movies2 三个 ZIP，合并解压到同一目录。最终目录应同时包含 `manifest.json`、`payload`（5 个 bin 文件）、`installer`、三个“安装或恢复”入口和本文说明。三个 ZIP 不需要拼接。

本项目仅提供差分，不提供游戏、官方升级、DLC、固件或授权。准备 BLJS10050 原版文件夹；需要升级/DLC 时，请先用你持有的官方 1.02 安装包及 DLC 完成安装，再打汉化。无需删除升级或 DLC。

退出游戏及模拟器。先保留独立存档备份；安装器不会修改 `savedata`。文件系统必须支持大文件，不要使用 FAT32。

目标磁盘建议至少留出 **12 GB 额外空闲空间**，用于重建游戏和已有缓存；原文件会保留为恢复备份，不会立即释放空间。三个 ZIP、解压后的差分数据还需另计约 5 GB。安装器会按待重建文件总量检查目标磁盘容量。

## 各系统入口

- Windows：安装 Python 3.9+，运行 `安装或恢复.bat`。可以使用 Python 官方安装器或已配置好的 Python；无需第三方 pip 包。
- macOS：运行 `安装或恢复.command`。若权限不足，在终端进入解压目录后执行 `sh 安装或恢复.command`。不要为了运行脚本关闭系统安全功能。
- Linux / Steam Deck：桌面模式下进入解压目录，执行 `sh 安装或恢复.sh`，需已安装 Python 3.9+。

入口提供“1 安装 / 2 恢复”。输入含 `PS3_GAME` 的游戏目录；RPCS3 数据目录应含 `dev_hdd0`，可通过模拟器菜单定位。不要输入 `dev_hdd0/game/BLJS10050` 作为数据根目录。

## 命令行安装

```sh
python3 installer/install_patch.py --game "/你的游戏目录" --rpcs3 "/RPCS3数据目录"
```

Windows 可把 `python3` 改为 `py -3`。路径含空格时保留引号。

不使用升级、且没有安装缓存时可省略 `--rpcs3`，此时只处理光盘资源。只要使用 1.02 或已有缓存，就应提供该参数，否则升级文字或缓存可能仍然是旧版。

安装器将验证所有选中原始文件与差分数据。任意一项不匹配会在替换前停止；目标全部重建、校验通过后才会替换，并保存 `.before-cn-时间戳` 原文件及游戏目录内的 `.suiten-cn-install.json` 恢复记录。再次安装同一版本会跳过已匹配文件。

## 恢复

先退出模拟器，再运行入口并选择“2 恢复”，或：

```sh
python3 installer/install_patch.py --game "/你的游戏目录" --restore
```

恢复会校验当前文件和备份，任何被其他补丁改动或缺失的文件都会导致停止。恢复覆盖本安装器记录的本体、升级和缓存，不修改存档、DLC 授权和模拟器配置。恢复后的汉化资源保留为 `.after-cn-时间戳`；确认不再需要后可自行删除。

请一起保留恢复记录及备份。仅重命名或删除记录不会自动恢复文件。先前由其他工具安装的汉化没有本工具记录时，应使用那个工具的备份恢复，不要让本工具猜测版本。

## 常见问题

- **manifest / payload 缺失**：通常只解压了一个 ZIP，或下载了 GitHub 的 Source code。重新下载三个附件并合并解压。
- **原始版本校验不匹配**：核对 BLJS10050、官方 1.02 和是否已装旧汉化。先恢复干净原版资源；不要改 manifest 中的哈希强行跳过。
- **出现旧文字**：检查是否启动了另一个游戏副本，以及安装时是否正确选择 RPCS3 数据目录。游戏会优先读 `dev_hdd0/game/BLJS10050/USRDIR/cache/game.arb`；本工具会同步已有缓存。
- **首次安装数据**：保留 `PS3_GAME/USRDIR/patch` 和 `dev_hdd0/game/BLJS10050/USRDIR/cache` 目录；不要在游戏安装数据时强退。文件访问错误 6 / 23 需结合日志定位，不能仅按错误号推定唯一原因。
- **缺少 DLC 内容**：本工具不会安装或解锁 DLC。核对你自己的官方升级、DLC 安装和游戏内解锁条件。
- **安装进度暂时没有逐秒输出**：单个影片文件可达数 GB，正在读取、重建或校验。不要在写入途中拔盘。
- **黑屏、彩条、低帧率**：这属于具体模拟器版本、配置或运行环境的排查范围；本汉化包不包含该类模拟器修复。原版同样有问题时，应先处理原版运行问题。

## 可选的安装/错误提示中文

`optional/system-message-localization.yml` 仅修改提示文本。可在 RPCS3 补丁管理器中导入并启用匹配版本的 `Chinese installation and error messages`，不要直接覆盖现有 `imported_patch.yml`。此文件不是启动修复，也不会修复读取错误。

## 完整性校验

macOS/Linux 可在下载目录运行 `shasum -a 256 -c SHA256SUMS.txt`；Linux 也可使用 `sha256sum -c SHA256SUMS.txt`。Windows PowerShell 使用 `Get-FileHash 文件名.zip -Algorithm SHA256`，与对应 `.sha256` 比对。完整性校验通过不等于全部游戏内容已经实机测试。
