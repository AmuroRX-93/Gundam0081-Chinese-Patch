## 下载与安装

从 **[20260917 首次汉化发行页](https://github.com/AmuroRX-93/Gundam0081-Chinese-Patch/releases/tag/v2026.09.17-delta.1)** 下载以下 **三个 ZIP**，缺一不可：

1. `Gundam0081_CN_Delta_20260917_r1_BLJS10050_Core.zip`：安装器、说明、本体和 1.02 升级汉化差分。
2. `Gundam0081_CN_Delta_20260917_r1_BLJS10050_Movies1.zip`：第一组影片差分。
3. `Gundam0081_CN_Delta_20260917_r1_BLJS10050_Movies2.zip`：第二组影片差分。

另附 `SHA256SUMS.txt` 和每个 ZIP 的 `.sha256`。附件按内容拆分，每个都是可独立解压的普通 ZIP，**不是 `.001/.002` 分卷，无需拼接**。把三个 ZIP 的内容合并解压到同一文件夹，保持 `manifest.json`、`payload/`、`installer/` 同级。

GitHub 的 **Code → Download ZIP** 和自动生成的 **Source code** 只含文档与源码，不含差分数据，不能用于安装。

1. 准备已解密、文件完整的 BLJS10050 原版目录，以及 **Python 3.9 或以上**。
2. 退出游戏和 RPCS3，完整解压三个 ZIP。
3. Windows 打开 `安装或恢复.bat`；Mac 打开 `安装或恢复.command`；Linux / Steam Deck 运行 `sh 安装或恢复.sh`。
4. 选择“安装”，输入直接包含 `PS3_GAME` 的游戏目录；使用 1.02 升级或已有安装缓存时，再输入直接包含 `dev_hdd0` 的 RPCS3 数据目录。
5. 安装器先核对原版和差分，再重建所有目标，校验通过后替换；保留原文件和恢复记录。已有 `cache/game.arb` 会同步修正。

详细操作、空间要求、恢复、缓存和报错说明见 **[安装与排错指南](docs/安装与排错.md)**。
