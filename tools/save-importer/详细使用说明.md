# 水天之泪存档导入器 0.2.0 · 详细使用说明

本工具把准备好的奖励存档导入 RPCS3，供《机动战士高达战记／水天之泪》BLJS10050 的离线自由任务使用。**已内置 Python 3.12 与图形界面运行组件，不需要安装 Python、pip 或联网下载依赖。**

这是独立存档工具，不是汉化补丁更新。不包含游戏本体、模拟器、固件、升级、DLC 安装文件或授权文件；请自行准备可正常运行的 **BLJS10050、1.02 升级和相应 DLC**。工具不会安装或授权缺失的 DLC。

最重要的一点：**导入预制存档会把所选槽位换成随包的初始进度，不是在你的当前进度上追加奖励。** 其他槽位、剧情档和系统档不会修改。已有同槽位存档会备份，确认前会列出来。

## 一、下载哪一份

在本工具的 GitHub 发行页下载一个 ZIP 即可，三份是独立完整包，不是分卷，不要合并。

| 你的电脑 | 下载文件 |
|---|---|
| Windows 台式机/笔记本，Intel 或 AMD 的 64 位处理器 | `SuitenSaveImporter-0.2.0-Windows-x64.zip` |
| Mac，M1／M2／M3／M4／M5 等 Apple 芯片 | `SuitenSaveImporter-0.2.0-macOS-AppleSilicon.zip` |
| Mac，Intel 处理器 | `SuitenSaveImporter-0.2.0-macOS-Intel.zip` |

Mac 点左上角苹果菜单 →「关于本机」：写“芯片 Apple M…”就用 AppleSilicon，写“处理器 Intel…”就用 Intel。Windows ARM 设备不属于本次原生适配范围。

不要下载 GitHub 自动生成的 **Source code** 来使用：那是源码，不含内置运行环境。网盘和 GitHub 的同名 ZIP 使用同一份文件，可用 SHA256SUMS 校验。

## 二、解压和启动

### Windows

1. 在 ZIP 上右键 →「全部解压」，选一个普通本地文件夹。不要在压缩软件内部直接双击运行。
2. 打开解压得到的 `SuitenSaveImporter-0.2.0-Windows-x64` 文件夹。
3. 双击 **`启动存档导入器.bat`**。可能会先出现一个终端窗口，随后出现图形界面；使用期间不要关掉它。
4. 程序使用同目录 `runtime\python.exe`，不会改系统 Python、环境变量或注册表。没有管理员权限要求。

### Mac

1. 双击 ZIP 解压，打开解压文件夹。
2. 双击 **`启动存档导入器.command`**。终端和图形界面会打开，使用期间保留终端。
3. 首次运行如被系统阻止，先确认来自作者发行页；按系统的「右键 → 打开」或「系统设置 → 隐私与安全性 → 仍要打开」提示处理本文件。若被拦截的是随包的 `runtime/bin/python3`，同样核对提示的具体文件。无需关闭整个 Gatekeeper 或修改系统 Python。
4. 若只提示 `.command` 没有执行权限，可打开终端输入 `bash `（后面一个空格），把 `.command` 文件拖进终端，再回车。

**不要单独移动启动文件或删掉 `runtime`、`saves`、`catalog.json`。** 要移动程序，请移动整个解压文件夹；要卸载，关闭程序后删除整个文件夹即可。导入过的游戏存档及其备份不会随程序删除。

## 三、选择正确的存档位置

1. **先完全退出 RPCS3**，不能只关游戏窗口而把模拟器留在后台。
2. 在工具窗口选择模拟器的**数据目录**，然后点「识别用户」。
3. Windows 可点击「选 rpcs3.exe」，选自己实际使用的模拟器程序；普通便携版会在旁边找到 `dev_hdd0`。也可以直接选 `dev_hdd0` 或具体 `savedata` 文件夹。
4. Mac 默认显示 `~/Library/Application Support/rpcs3`。如果你改过位置，手动选择实际目录。
5. 上方下拉框会列出发现的用户路径。若有多个用户，不会擅自选第一位，必须选你实际游玩的用户。

常见目录示例：

```text
Windows：D:\RPCS3\dev_hdd0\home\00000001\savedata
Mac：~/Library/Application Support/rpcs3/dev_hdd0/home/00000001/savedata
```

`00000001` 只是常见用户编号，不保证每个人都相同。先在 RPCS3 的用户管理和已有存档位置中核对。若不确定，可在 RPCS3 的存档管理器中找到已有水天之泪存档并打开所在目录；找到后退出 RPCS3，再在本工具中选它的上一级 `savedata`。

**不能选择游戏 ISO、EBOOT.BIN、Game 或 PS3_GAME 来代替模拟器目录。** 游戏本体和用户存档分开存放，同一游戏还可能被多套模拟器使用。若改过虚拟文件系统映射，请直接选实际 `dev_hdd0/home/用户编号/savedata`；工具不会猜测或改写映射。

没有用户目录时，请先按正常流程初始化 RPCS3 固件/用户；建议先自行启动游戏创建普通存档、退出，再导入。本工具不会代替你初始化模拟器。

## 四、四份存档怎么选

可以只勾一份、勾多份，或点「全选四份」。每份的目标槽位固定，不会因为勾选顺序改变。

| 界面名称 | 目标槽位 | 奖励内容 |
|---|---|---|
| 联邦 · 联机独占 | E01 | 45 种武器/盾牌、36 种部件；保留 3 台初始机体 |
| 联邦 · 全部可解锁 | E00 | 132 种武器、121 种部件、98 种机体，共 99 台 |
| 吉翁 · 联机独占 | Z01 | 45 种武器/盾牌、36 种部件；保留 3 台初始机体 |
| 吉翁 · 全部可解锁 | Z00 | 132 种武器、121 种部件、98 种机体，共 99 台 |

- **第一档**面向希望继续正常离线游玩、只补联机独占奖励的玩家，不把有离线来源的所有内容一并发放。
- **第二档**采用已核实的完整奖励清单。13 件来源未确认的武器未加入，因此“全部可解锁”是档位名称，不能理解成已经证明 100% 全物品覆盖。
- 普通物品目标数量为 3，改修材料目标数量为 10，装备中的数量也计入核对。
- 四份均为自由任务初始进度、5,000 点积分；不是剧情通关档，不会继承你已有的任务进度、机体改装或驾驶员培养。
- 两种阵营分别准备，不能仅通过重命名把联邦档变成吉翁档。请使用对应条目。

## 五、预览、确认和导入

1. 点击「预览导入内容」，核对**目标用户、完整路径、所选档位与操作**。
2. 「新增」表示此槽位不存在；「备份并替换」表示已有存档会换成随包进度；「已一致，跳过」表示无需重复写入。
3. 若任何槽位是你不想替换的进度，取消对应勾选。程序不会自动挑一个其他槽位来隐藏冲突。
4. 点击「导入所选存档」。确认框再次列出内容，确认后才写入。
5. 成功后界面会显示结果及 `receipt.json` 备份记录位置。保存好这个路径。

导入前检查随包文件、原存档、剩余空间、RPCS3 进程和并发导入锁；仅修改所选的 E00/E01/Z00/Z01 槽位。写入后再读回核对。普通写入异常会尝试回滚本次操作，但不要在操作中拔掉硬盘、断电或强制结束进程。

## 六、游戏里在哪里看

1. 正常启动水天之泪，进入**自由任务 → 读取存档**，选择对应阵营和存档。
2. 读档列表的说明已加入「联邦/吉翁 · 联机独占/全部可解锁」标签。部分界面可能不展示全部 SFO 信息，下一次保存也可能重写描述；可以结合阵营和 E00/E01/Z00/Z01 目录核对。
3. 进入后在**仓库**查看武器、盾牌和强化部件，在**机库**查看机体。
4. 第二档应有 99 台机体（98 种，含一台重复初始机体）；第一档保持 3 台初始机体。
5. 不要载入导入前的模拟器即时状态，否则可能恢复旧的内存进度。请从游戏正常读档开始。

“导入成功”表示文件已写入并回读校验，不等于所有任务已经实测通关。四份存档的后续任务推进、保存后重读仍需游戏内验证。建议先正常读档确认仓库和机库，再开始长期游玩。

## 七、备份在哪里，怎样恢复

备份与 `savedata` 同级，例如：

```text
dev_hdd0/home/00000001/
├─ savedata/
└─ SuitenSaveBackups/
   └─ 20260924-时间-编号/
      ├─ receipt.json
      └─ before/                原有存档的完整备份
```

只备份本次会替换的存档，不备份整个游戏。新建槽位没有原档，对应恢复操作会把它撤回。

恢复步骤：

1. 完全退出 RPCS3。
2. 打开工具，点击「恢复原档」。
3. 选择对应时间备份目录中的 `receipt.json`，确认恢复。
4. 程序检查当前存档仍与导入结果一致，再恢复原档；恢复后重新启动游戏读档。

**若你导入后继续游玩并保存，自动恢复会拒绝覆盖新进度。** 这时先保存当前存档和旧备份，请求检查后再决定保留哪一份，不要删除校验记录来强行恢复。备份中的绝对路径属于本机，移动 RPCS3 数据目录后也需要核对路径，不能直接把他人的 receipt 当作自己的恢复记录。

## 八、常见问题

| 现象 | 处理方法 |
|---|---|
| 提示找不到 Python | 本版不依赖系统 Python。确认下的是 0.2.0 便携 ZIP，而非 Source code 或 0.1.0；完整解压，并检查 runtime 是否被遗漏或隔离。 |
| 窗口一闪而过 | 从终端运行本包启动文件查看错误。检查平台包是否选错，不要从 ZIP 内运行；保留错误原文。 |
| Mac 提示 bad CPU type | 芯片版选错。Intel Mac 用 Intel 包，M 系列用 AppleSilicon 包。 |
| Windows 拦截或隔离文件 | 先核对官方发行页与 ZIP 校验值；检查安全软件记录中的具体文件。不要关闭全局防护来运行来源不明的副本。 |
| 找不到 RPCS3 用户 | 选择实际数据目录，而不是游戏目录；若自定义 dev_hdd0，直接选其 savedata。先初始化模拟器用户。 |
| 提示 RPCS3 正在运行 | 完全退出模拟器，再试。工具不会替你强制结束进程。 |
| 文件校验失败 | 不要手改 catalog.json 或删掉文件；重新完整解压同一版 ZIP。 |
| 提示路径是符号链接、目录联接 | 选择实际存储目录。本工具保守拒绝链接和 Windows 重解析路径。云同步目录可能也被拒绝，请用普通本地目录。 |
| 预览后原档变了 | 退出游戏，重新预览，确认没有另一个导入器或同步软件写入。 |
| 空间不足或没有写权限 | 释放目标磁盘空间，确认账户对模拟器数据目录有写权限；不要默认用管理员权限强行写入系统文件夹。 |
| 导入了但游戏看不到 | 核对是不是同一套 RPCS3、同一个用户、BLJS10050 和自由任务模式；确认 1.02/DLC 资源完整，正常重启并读取游戏存档。 |
| 有物品但模型/功能异常 | 存档不会补装 DLC 或游戏资源，先核对游戏版本及 DLC；保留该档和问题截图，勿立刻覆盖全部存档。 |
| 提示导入锁存在 | 可能另一个导入程序仍在运行，或上次操作被中断。先保留整个备份目录，检查 receipt.json 状态；不要直接删锁重复写入。 |

断电/强制退出后：先保留 `SuitenSaveBackups` 和 `.suiten-import.lock`。`before` 为经校验的原档；`old`、`new`、`restore-*` 可能记录未完成事务。`receipt.json` 的 installing/prepared 状态不能当作成功，需按记录检查后恢复。不要随意清理这些目录。

## 九、终端用法（可选，无需系统 Python）

先在终端进入完整解压的工具文件夹。默认只预览；`--apply` 才执行写入。

Windows：

```bat
runtime\python.exe -I -B launch.py --target "D:\RPCS3\rpcs3.exe" --profile 00000001 --select all
```

Mac：

```sh
./runtime/bin/python3 -I -B launch.py --target "$HOME/Library/Application Support/rpcs3" --profile 00000001 --select all
```

确认后在末尾加 `--apply`。单份可将 `all` 换成 `e-online`（联邦第一档）、`e-all`（联邦第二档）、`z-online`、`z-all`，多份用空格分开。

恢复示例（Mac）：

```sh
./runtime/bin/python3 -I -B launch.py --restore "/实际备份位置/receipt.json" --apply
```
