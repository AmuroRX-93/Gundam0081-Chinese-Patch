# 第三方运行时说明

本包随附 **CPython 3.12.14**，采用 Astral 维护的 python-build-standalone **20260901** 构建（install_only_stripped），包含本工具需要的 Tcl/Tk。三种架构分别打包，程序直接使用同目录 runtime，不要求用户另行安装，也不会替换系统 Python。

上游：
- https://github.com/astral-sh/python-build-standalone/releases/tag/20260901
- https://gregoryszorc.com/docs/python-build-standalone/main/distributions.html
- https://www.python.org/

每份下载包的原始 URL、大小、SHA-256 记录在 runtime-source.json；构建时按该摘要验证。runtime 目录中的许可和版权文件保持保留；额外依赖的许可见随包的许可证目录。仅去除运行生成的 __pycache__，未重新编译解释器或更改许可证。
