## 开始前

1. 先有完整的 `20260917_r1` 汉化版，以及已汉化的官方 1.02 更新。原版用户先按 [旧版发行页](https://github.com/AmuroRX-93/Gundam0081-Chinese-Patch/releases/tag/v2026.09.17-delta.1)安装三个 ZIP 的首次汉化，再使用本包。
2. 安装 Python **3.9 或以上**（仅用标准库）。需要安装时使用 [Python 官方网站](https://www.python.org/downloads/)。
3. 保存进度并完全退出 RPCS3。安装器会检测进程，避免修改正在读取的资源。
4. 将本升级 ZIP 完整解压到独立文件夹。`install_upgrade.py`、`launcher.py`、`upgrade-manifest.json`、`payload/` 须保持同级。不要合并到旧首次安装器文件夹。
5. 游戏目录所在磁盘预留至少 **512 MB**，RPCS3 数据所在磁盘也预留 **32 MB**。需要约数百 MB 可用内存。备份只保存变更区间及两份更新文件，不复制整个游戏。

## 图形桌面的启动入口

- Windows：双击 `升级或恢复.bat`。
- Mac：双击 `升级或恢复.command`；若无法双击，可在终端执行 `sh` 后拖入该文件。
- Linux / Steam Deck：终端运行 `sh 升级或恢复.sh`。

工具以文字菜单操作，不会启动游戏。

先选 **2 只检查**，通过后重新运行选 **1 安装升级**。准备两个目录：

- **游戏目录**：里面直接有 `PS3_GAME`。例如 `D:\Games\水天之泪`。不要选择 `USRDIR`、ISO 或模拟器快捷方式。
- **RPCS3 数据目录**：里面直接有 `dev_hdd0`。Windows 常在 RPCS3 主目录；macOS 通常是 `~/Library/Application Support/rpcs3`；Linux 通常是 `~/.config/rpcs3`。便携版、自定义数据目录须按实际位置选择。

安装器检查游戏编号、更新版本、全部目标资源和差分 SHA-256，通过后才开始写入。本体与已有 `dev_hdd0/game/BLJS10050/USRDIR/cache/game.arb` 一起更新；没有缓存时不主动创建。两份 1.02 更新汉化资源也会同步处理。

安装完成后，**由你手动启动游戏**。已有存档继续使用，不需要开新档。本包不会读取或修改 `savedata`、影片、模拟器配置和 EBOOT；已有低特效修改只要不改动本次目标资源即可保留。未知版本或混合版本会被拒绝，不能靠改文件名绕过校验。

## 恢复、重复安装与安装中断

恢复只撤销**这次升级**，回到安装本包前的旧汉化状态，不移除原汉化，也不覆盖此前存在的低特效修改。

1. 完全退出 RPCS3。
2. 运行本包入口选择 **3 恢复本次升级**，输入同一个游戏目录。或者：

```sh
python3 install_upgrade.py --game '/你的游戏目录' --restore
```

游戏目录的隐藏文件夹 `.suiten-cn-upgrade-20260925` 保存事务记录、安装前字节和恢复校验数据。**需要恢复时不要删除它，也不要移动游戏或 RPCS3 数据目录**；恢复记录使用安装时的本机路径。备份只留在本机，不应随补丁转发。

安装中断时保持 RPCS3 关闭，先选恢复，再重装。本包对已完成的重复安装不再写入；混合版本且缺少本包恢复记录时会拒绝，需找回对应备份，不能强装。恢复前会检查所有备份与目标，发现安装后目标区间另有修改就停止，以免覆盖新内容。

若要卸载最早的首次汉化，应**先恢复本升级，再用 20260917 首次安装器恢复**。不要直接拿旧首次安装器覆盖新版。

## 常见问题

- **找不到 PARAM.SFO / dev_hdd0**：选错目录，或官方 1.02 更新未安装。本包不提供官方更新。
- **更新资源版本不匹配**：更新可能尚未汉化、不是本包支持的旧版，或被其他补丁修改；先确认是 20260917_r1 汉化的 1.02。
- **差分包损坏 / 找不到 payload**：重新完整解压 ZIP；用附带 `.sha256` 核对下载。GitHub “Source code” 不含差分数据，无法用于安装。
- **目标只读 / 空间不足**：关闭占用程序、修正目录权限、腾出空间，再检查；不要关闭系统安全保护。
- **RPCS3 仍在运行**：正常退出并等待后台进程结束；本安装器不会替你强制结束程序。
- **更新后仍看到旧界面**：确认实际启动的是所选游戏目录，数据目录也是该 RPCS3 实际使用的位置。不要删除存档。
